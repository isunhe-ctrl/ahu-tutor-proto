控制回路识别

为空调机组送风温度串级控制回路标注各元件角色，提交后即时纠错并解析。

变风量系统控制回路

识别“区域温度传感器 → VAV 控制器 → 末端风阀 → 区域风量/温度”的回路，并理解主风管静压传感器对风机变频的外层约束。

学习任务：标出区域设定值、温度偏差、风阀开度、风量反馈、静压设定值和风机频率。

风机盘管加新风系统回路

识别“室内温控器 → 二通水阀/风机三速”和“CO₂/新风温湿度 → 新风机组”的两条协同回路。

学习任务：说明房间显热、室外新风、湿负荷和盘管水阀之间的分工。

PID 参数整定虚拟实验

实验顺序：先用比例控制观察稳态误差，再逐步增加积分消除误差，最后谨慎加入微分抑制扰动超调。每次只改变一个参数并记录超调量、稳定时间和稳态误差。

  1. 使用“典型不良参数”记录响应特征。
  2. 点击“推荐参数”作为初始值。
  3. 分别改变 Kp、Ki、Kd，比较负荷扰动下的响应曲线。

故障诊断训练

随机生成传感器/阀门/加湿/风量故障，按“现象—原因—验证—处理”闭环分析并提交。

冬季盘管防冻专项

典型联锁顺序：低温预警 → 关小/关闭新风阀 → 打开热水阀至保护开度 → 停止送风机或切断冷源 → 报警并保持人工复位条件。

诊断任务：核对室外温度、防冻开关、盘管出水温度、新风阀反馈、热水阀反馈和风机运行状态，避免只复位报警而未排除根因。
